# Full test pass and design review — November 5, 2026

Candidate: `main` at `2108fac` (No due date column scrolls, and the work merged before it), then the fixes from this pass on the `test-pass-fixes` branch.

The UX rules were reviewed against the code by four independent readers, one for each group of documents, and their findings were checked before being acted on. The maintainer decided each one.

## Automated checks

Passed on macOS on the final commit:

- `npm ci`, lint with zero warnings allowed, and TypeScript checking.
- **886 tests across 63 files**, and **8 Python shortcut tests**.
- The browser harness build and packaging.

## Browser harness (Chromium)

- Wide, and 375px with touch emulated: the No due date column with the setting on and off, a board with no such column, What's new from the toolbar and after an update, and Appearance.
- `?load=2000`: 225 cards drawn of 2,000, **N more** works, no console errors, and no sideways page scroll at 375px.

## Native macOS Obsidian

All checks used the disposable "Task Trellis Readiness Test" vault with synthetic tasks and Tasks 8.6.0, with real clicks, keys and wheel events unless noted. Drags went through Chromium's own drag path using the DevTools protocol, not a physically held mouse.

- **Cards:** the composer and subtask composer, completing, Alt+Down, Move to…, the scheduling arrow, Undo for each, and Undo leaving a newer edit alone.
- **Drags:** across columns, to No due date, to and from Done, a subtask out of its card, cancelled drags, and a gap low in a long No due date column.
- **Board tools:** collapsing rows, Arrange, Sort by due date, search, quick filters on the toolbar and in the menu, the column picker, selection and bulk edits, labels, the Tasks editor and the note pop-up.
- **Settings:** tab order and the remembered tab, renaming, removing and reordering columns, quick filters, suggested color rules, filter groups, New tasks, Rename board…, Duplicate board… and Delete board….
- **Other:** New board and its templates, a taken name, What's new, the Add task commands, and the boards sidebar's Add task.
- **No due date column scrolls:** on and off, from Appearance and What's new, a forced write failure, and a board with no such column.
- **Layouts:** a 476px board and back across 600px, the light theme, reduced motion (emulated), 150% zoom, and Obsidian's mobile layout on the Mac (`app.emulateMobile`), which isn't a real device.

## Found and fixed

| Issue | Result |
| --- | --- |
| Opening another Add task box threw away what was typed in the first | Its text and labels come back when it's opened again |
| A long No due date column overflowed its box, and a drop in a gap past it did nothing | The box contains its cards, without stretching the rows |
| After the bulk editor or Undo while selecting, focus fell to the page and Escape stopped working | Focus stays on the board |
| A click in the bulk bar that missed its buttons dropped the selection | It keeps the selection |
| Selecting took away the strike-through and overdue bar | Cards keep them |
| Search couldn't find an old completed subtask its card shows | It can; quick filters keep their age limit |
| On its own still scrolled separately with only that column chosen | It scrolls with the board |
| A failed Sort by due date said it had sorted | It says nothing moved, or how many stayed |
| Escape closed a task box only from its text | It closes from anywhere in the box |
| More in a capped cell left focus on Show fewer, and a just-moved card could drop behind it | Capped cells follow the same rules as others |
| Small touch targets, and 28px icons in Obsidian mobile with a trackpad | 44px tap areas with the same look |
| Focus lost on a redraw from the source link and Add subtask | The link keeps it, and others hand it to their card |
| A quick filter from the menu ended selection mode | It acts as it does on the toolbar |
| Task not saved could be dismissed during a retry, gave no confirmation, and could fail for good | All three fixed |
| Failures that were silent or not spoken, and notices without a next step | Every notice goes through the helper, with what to do next |
| Repeated icon buttons didn't name their task, and a general settings error wasn't said | Named, and said with focus moved to it |
| A partly successful bulk edit gave only counts | It names the skipped tasks |
| What's new's checkbox sizes, the gray focus ring in dialogs, errors in the warning color, and gaps in reduced motion | Fixed |
| A search during input method composition, Escape in a label's editor, and labels on subtask cards while selecting | Fixed |
| Disabling a name editor's check dropped focus | Focus moves to the name first |

Wording slips, out-of-date docs and the command line guide were corrected. The maintainer chose to keep the filled look of buttons in Obsidian, so the rules now describe it. The differences the maintainer chose to keep are recorded under each document's Exceptions.

## Not tested

- Real iPhones, iPads and Android devices, including the phone keyboard and the new tap areas. Obsidian's mobile layout on a Mac and a phone-width browser don't establish them.
- VoiceOver. Live regions, names and focus moves were checked in the DOM only, and the extra status regions recorded under Accessibility's Exceptions need listening to.
- Windows and Linux.
- Drags with a physically held mouse, and the Arrange checkmark in macOS's native menu.
- Real sync conflicts. Stale writes and Undo were checked with edits made by a script, in the vault and in automated tests.
