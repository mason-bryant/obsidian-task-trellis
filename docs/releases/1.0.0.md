# Task Trellis 1.0.0

Task Trellis 1.0 promises that your boards, labels, notes and scripts keep working through every 1.x release. [Formats and compatibility](https://github.com/mason-bryant/obsidian-task-trellis/blob/1.0.0/docs/compatibility.md) lists what that covers. Task Trellis is now in Obsidian's Community directory: install or update it from **Settings → Community plugins**.

## Large boards on phones

- Long cells show 25 cards at a time. **N more** shows the next 25, and **Show fewer** goes back. A 2,000-task board that used to restart Obsidian on iPhone now opens and stays up.

## Screen readers

- Results are now spoken: Task moved, Subtask reordered, a column's new position in settings, selection counts and filter warnings. Obsidian doesn't speak its own pop-up notices, so notices about a board are also said from the board, with failures as alerts.
- Column separators say which column they resize, and each Add task button says which column and row it adds to.
- Saving with the composer's check keeps keyboard focus in the composer, ready for the next task.

## Adding tasks

- Templater folder templates now apply to notes Task Trellis creates. The task waits for the template, then goes under the template's heading.
- A task added to the end of a note that already ends with a list no longer gets a blank line before it.
- Adding to a brand-new note no longer warns that the board's filters may hide the task before Obsidian has read the note.
- The [command-line guide](https://github.com/mason-bryant/obsidian-task-trellis/blob/1.0.0/docs/cli.md) now tells macOS users to run `obsidian-cli`, because `obsidian` can print nothing for slower commands.

## Board settings

- The button at the end of the form is now **Save**, with a green check. It does what the header's check does. The board is already open whenever its settings are, so the old Save & open board added nothing.

## Compatibility and migration

Requires Obsidian **1.13.7 or later**. Existing boards, notes and settings carry over; no migration is needed for anything 0.1.15 or later wrote.

1.0 no longer reads three formats from before 0.1.15:

- `<!-- tt-labels:… -->` label comments. Labels are tags, `#tt/<board>/label/<id>`.
- The `due-now-days` board property. Use `due-now` and `due-now-unit`.
- Compact remembered per device. Compact is now only the board's **Card spacing** setting, saved in the board note, so it's the same on every device. If a board looked compact on one device only, choose Compact in its Appearance settings.

## Validation

- **Automated:** 681 application tests and 8 shortcut tests, lint, TypeScript checking, the harness build and packaging.
- **Native macOS:**
  - Obsidian 1.13.7 and 1.14.5, in a disposable vault with synthetic tasks.
  - Upgrading from 0.1.16, and 0.1.16 sharing board settings with this version.
  - Subtask reordering by mouse and keyboard, and 2,000-task boards.
  - Tasks and Templater, Daily notes, turning the plugin off and on with boards open, and the command line.
  - After the final merges: boards and cell paging, subtask reordering with its spoken status and Undo, the composer, board settings, the new Save button and the command line.
- **VoiceOver on macOS:** a keyboard-only pass before the screen-reader fixes found the problems they address. In the same Obsidian window, VoiceOver spoke a status region that stays in place and changes, which is how the fixes announce results. The fixed build hasn't yet been checked by ear.
- **iPhone, through iPhone Mirroring:** the 2,000-task board opened and stayed up, and paging and selection worked. **N more** and the on-screen keyboard weren't checked on the phone.
- **Not tested:** Android, iPadOS, Windows and Linux.

Details are in the [October 30 report](https://github.com/mason-bryant/obsidian-task-trellis/blob/1.0.0/docs/qa/native-2026-10-30.md) and the [large-board report](https://github.com/mason-bryant/obsidian-task-trellis/blob/1.0.0/docs/qa/large-board-2026-10-30.md).
