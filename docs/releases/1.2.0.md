# Task Trellis 1.2.0

## Add a task to a column with a hotkey

Every board now has an **Add task to ‹board›: ‹column›** command for each column but Done, such as **Add task to House: Doing**. Give it a hotkey in **Settings → Hotkeys**; search for the board's name.

- **From anywhere:** the command opens the Tasks plugin's editor, or a plain prompt without it, so you don't need to open the board.
- **Where the task goes:** the top of that column, with no due date unless you set one, in the board's New tasks note, just as if you'd used **+ Add task** on the board.
- **A notice says where it went.** On a board with a No due date column, an undated task shows there until it has a due date, and the notice says so.
- **Cancelling** the editor adds nothing.

Hotkeys survive renaming the board note. Renaming a column, or renaming the board's tags, gives its commands new ids, so set those hotkeys again. See [Add a task](https://github.com/mason-bryant/obsidian-task-trellis/blob/1.2.0/docs/tasks.md#add-a-task).

## Board settings ask before discarding changes

If you've changed a board's settings without saving, the X, Escape or a click outside the dialog now asks first:

- **Keep editing,** which has focus, takes you back to your changes.
- **Discard changes** closes the settings without saving.

With nothing changed, after saving, or after deleting the board, the settings close straight away, as before. The other editors, which hold just a name or a few choices, still close without asking.

## Compatibility

Requires Obsidian **1.13.7 or later**. No note, tag or property format changes: everything 1.1.0 reads and writes stays the same, as [Formats and compatibility](https://github.com/mason-bryant/obsidian-task-trellis/blob/1.2.0/docs/compatibility.md) promises. The new commands add nothing to your notes until you use them.

## Validation

- **Automated:** 762 application tests and 8 shortcut tests, lint, TypeScript checking, the harness build and packaging.
- **Native macOS, Obsidian 1.14.5,** in a disposable vault with synthetic tasks, using the packaged release files:
  - **Add task to ‹board›: ‹column›:** run from another note, it opened the Tasks editor and wrote the task under the board's New tasks heading with the column's tag. The notice named the board and column, and the card appeared. Cancelling changed nothing.
  - **Unsaved changes:** the X, Escape and a click outside each asked first, with Keep editing focused. Keep editing returned to the draft, and Discard changes closed without writing the board note. With nothing changed, the settings closed at once.
  - **1.1.0 features:** the General tab's Rename, Duplicate and Delete, and the filter editor, still work.
  - **No side effects:** every note was unchanged afterwards, and Obsidian's error log was clean.
- **Before tagging:** the same code was installed in the maintainer's own vault.
- **Not tested:** phones (iPhone and Android), binding a hotkey in the Hotkeys settings, listening with VoiceOver, iPadOS, Windows and Linux.
