# Task Trellis 1.0.1

## Delete a board

Board settings now open on a new **General** tab, which holds the date settings that used to have their own tab and ends with a red **Delete board…** button. A warning names the board's note and says plainly that none of your tasks will be deleted. **Delete board** then moves only the board note to the trash, following Obsidian's **Files and links → Deleted files** setting, and closes the board. Every task stays in its note exactly as it was, with the board's tags, so restoring the note from the trash brings the board back.

## Sort a board by due date

The toolbar's Subtasks button is now **Arrange**. Next to Collapse all subtasks and Expand all subtasks, its menu has **Sort by due date**, which puts every date row's cells in order, sooner first, in every column except Done.

- It moves as few cards as it can: cards already in order stay put, and only the others get a new order number.
- Same-date cards keep their order.
- Cards hidden by quick filters are sorted too, and other boards aren't touched.
- One **Undo** puts every card back.

## Removing a column

Before you save, the Columns tab now says how many open cards a removed column has and which column they'll show in instead. Their tags aren't changed, so adding the column back returns them.

## Compatibility

Requires Obsidian **1.13.7 or later**. No note, tag or property format changes: everything 1.0.0 reads and writes stays the same, as [Formats and compatibility](https://github.com/mason-bryant/obsidian-task-trellis/blob/1.0.1/docs/compatibility.md) promises. The date settings moved from the Dates tab to General.

## Validation

- **Automated:** 706 application tests and 8 shortcut tests, lint, TypeScript checking, the harness build and packaging.
- **Native macOS, Obsidian 1.14.5,** in a disposable vault with synthetic tasks:
  - **Delete board:** the warning's wording, and Cancel focused first. After deleting, the note was in the trash and the board's tab, sidebar entry and command were gone. The task notes were byte-for-byte unchanged, and restoring the note brought the board back.
  - **Sort by due date:** through Obsidian's native Arrange menu, it rewrote exactly the predicted lines on a scrambled board. Done, undated cards and another board's tags were untouched, and Undo restored the note exactly.
- **Browser harness:**
  - the General tab and Delete board, in light and dark themes at desktop and phone width;
  - the Arrange menu;
  - the removed-column note, in dark at 760 px and light at 375 px.
- **Before tagging:** the same code was installed in the maintainer's own vault.
- **Not tested:** phones (iPhone and Android), the removed-column note in native Obsidian, listening with VoiceOver, iPadOS, Windows and Linux.
