# Task Trellis 1.1.0

## Combine filters with and, or and not

A board's filters can now say "show tasks in my Work folder, **or** tagged `#work` anywhere", which before could only be "and". The Filters tab works like the filter editor in Obsidian's Bases:

- **Groups:** each group has a dropdown, **All the following are true**, **Any of the following are true** or **None of the following are true**, and **where**, **and** or **or** in front of each filter.
- **Nesting:** select **Add filter group** to put a group inside a group, up to three levels deep, for logic like ((A or B) and C) or D. A nested group shows as a card, with its own **Add filter** and a trash button.
- **Filters:** each filter is one box: Tags, Note folder or Note property, then the values, then its trash button. Change what a filter tests from its first dropdown.
- **One note:** a Note folder filter can also name one note's path, such as `Projects/Plan.md`, to match just that note.
- **Quick filters** get the same editor for their tag, folder and property filters.

Existing boards open with their filters as an All group, with their exclusions in a None group, and show exactly the same tasks. See [Choose which tasks appear](https://github.com/mason-bryant/obsidian-task-trellis/blob/1.1.0/docs/filters.md).

## Duplicate and rename boards

**Settings → General** has two new buttons:

- **Rename board…** opens the same editor as clicking the board's title, and returns you to the settings with any unsaved changes still there.
- **Duplicate board…** makes a new board next to the original, with its saved settings: columns, labels, filters, quick filters, appearance and where new tasks go. It gets its own tag prefix and opens in a new tab. No task is copied or changed: the copy shows the same tasks, with open cards starting in its first column, such as Backlog, and no labels.

## Add tasks from the boards sidebar

Under the open board in the boards sidebar, **+ Add task** opens the same composer as a board cell, and adds the task to the top of that board's backlog. Your draft stays with its board when you switch boards.

## Pick labels for a new task

The task composer, in board cells and in the sidebar, has a **Labels** button (the tag icon). It opens the same picker as a card. The labels you pick show above the text box and are added with the task.

## Fixes

- **Delete board…** and the warning's **Delete board** are red in Obsidian, as intended; Obsidian's own button style was overriding them.
- Subtle buttons, such as **Add column** and **Add quick filter**, no longer get a background in Obsidian.
- The board name field has focus, with the name selected, when the **Rename board** dialog opens.

## Compatibility

Requires Obsidian **1.13.7 or later**. Boards whose filters fit the lists earlier versions use are saved exactly as before, and every board 1.0.x wrote opens unchanged, as [Formats and compatibility](https://github.com/mason-bryant/obsidian-task-trellis/blob/1.1.0/docs/compatibility.md) promises.

Filters that need groups are saved in a new `filter` property, which versions before 1.1.0 can't read. So that an older version on another device doesn't show tasks the filter hides, those boards also get a folder rule no note matches: older versions show that board, or that quick filter, with no tasks until they're updated. **Update Task Trellis on every device before using filter groups.** Removing the groups returns the board note to the plain lists.

## Validation

- **Automated:** 752 application tests and 8 shortcut tests, lint, TypeScript checking, the harness build and packaging.
- **Browser harness:**
  - the filter editor with three levels of groups, in dark and light themes, at desktop width and 375 px;
  - the General tab's Rename and Duplicate dialogs;
  - the sidebar and board composers with labels, including 375 px with touch emulation.
- **Native macOS, Obsidian 1.14.5,** in a disposable vault with synthetic tasks:
  - **Filter groups:** built and saved through the editor, then reopened. The board showed exactly the expected cards. Removing the groups restored the board note byte for byte. The 1.0.1 build showed no cards for the grouped board, as intended.
  - **Duplicate board:** with and without unsaved settings, it wrote one note with identical settings and a new slug, which opened and appeared in the sidebar. **Rename board…** from the settings kept their draft.
  - **Sidebar and labels:** adding from the sidebar with a label wrote one line, with the label, first in the backlog. The board cell composer's Labels button worked too.
  - Every other note was unchanged, and Obsidian's error log was clean.
- **Before tagging:** the same code was installed in the maintainer's own vault.
- **Not tested:** phones (iPhone and Android), listening with VoiceOver, iPadOS, Windows and Linux. On a phone, the long group dropdown text can be slightly clipped at the third level.
