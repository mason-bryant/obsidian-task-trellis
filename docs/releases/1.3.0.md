# Task Trellis 1.3.0

## Search a board

Every board has a **Search cards…** box at the right of its name. Press **Cmd/Ctrl+F** in a board to jump to it.

- **What it matches:** every word you type must be in the card's text, its note's name or its label names. Case and accents don't matter, so `cafe` finds "Café".
- **Subtasks:** a matching subtask brings in its card, opened to show it. Words the card itself doesn't contain must all be in the same subtask, so `kitchen trim` finds the Kitchen card through "Paint the trim".
- **With filters:** search narrows the board on top of its filters and quick filters. **Select all** then picks only the matches.
- **Keys:** the board updates as you type. **Enter** moves to the first matching card, and **Escape** or the **×** clears the box.
- **No matches:** the board says so and offers **Clear search**, plus **Turn off quick filters** when any are on. Screen readers hear how many cards match.

The search lasts while the board stays open in its tab; it isn't saved. See [Search the board](https://github.com/mason-bryant/obsidian-task-trellis/blob/1.3.0/docs/filters.md#search-the-board).

## Color cards with rules

A new **Colors** tab in board settings tints the cards that match rules, such as everything in a client's folder or every high-priority task.

- **A rule** has a name, a color from the label palette or an HTML color code, and the same choices as a quick filter: **Priority**, **Labels**, **Due**, and filters for tags, note folders and note properties, in groups.
- **Order:** a card takes the color of the first rule it matches. Drag rules to put them in order.
- **On the board:** a light tint, a little stronger in dark themes, so text stays readable. Subtasks share their card's color, overdue cards keep their red edge, and colors never change which cards show. Screen readers hear the rule's name with the card.

See [Color cards](https://github.com/mason-bryant/obsidian-task-trellis/blob/1.3.0/docs/filters.md#color-cards).

## Smaller changes

- A card scrolled into view, by Tab or by the search's Enter, now stops below the sticky column header instead of under it.
- Quick filters and color rules share one editor in board settings, so they look and work the same.

## Compatibility

Requires Obsidian **1.13.7 or later**. Existing boards show the same cards, and no note, tag or existing property changes. Color rules are saved in a new `color-rules` board property, written only when a board has rules and removed with the last one. Earlier releases ignore it, so they show such a board's cards without colors. Searches aren't saved anywhere.

## Validation

- **Automated:** 786 application tests and 8 shortcut tests, lint, TypeScript checking, the harness build and packaging, locally and in CI.
- **Browser preview (the harness):** desktop width and phone width (375 px), in dark and light themes. Checked:
  - The search box's place in the toolbar, typing while the board redraws, Enter, Escape, the clear button and the no-match message.
  - The Colors tab, card tints, overdue cards and selection mode.
- **Native macOS, Obsidian 1.14.5,** in a disposable vault with synthetic tasks, using the packaged release files, with real key presses and clicks:
  - **Search:** Cmd+F jumped to the box, and typing narrowed the board while keeping focus. Screen readers were told "1 card matches “roof”.", Enter moved to that card, a word with no matches showed the message and Clear search, and Escape cleared the box. Cmd+F in an ordinary note still opens note search.
  - **Color rules:** added two rules in the settings dialog, one with a palette color and a folder filter, one with priorities and a typed color code. A malformed code was refused and the field marked, and the board recolored as soon as the settings were saved. Checked in light and dark themes, and with quick filters, search and selection mode on. Removing the rules restored the board note exactly.
  - **Unchanged:** the quick filter settings (Show on board, Match subtasks, cloning) and asking before discarding unsaved settings.
  - **No side effects:** Obsidian's error log was clean.
- **Before tagging:** the same code was installed in the maintainer's own vault.
- **Not tested:**
  - Phones (iPhone and Android), including whether the phone keyboard stays open while search results update.
  - Listening with VoiceOver.
  - A real input method such as Japanese; only simulated composition events.
  - iPadOS, Windows and Linux.
