# Task Trellis 0.1.17

## Keep quick filters within reach

- Put some or all quick filters in a menu, with an optional number to keep visible on the toolbar. Set a separate limit for single-column layouts, or inherit the desktop setting.
- Drag quick filters into order using the narrow right-side grip. The moving row and insertion space show where it will land; keyboard reordering is also available. Columns use the same settings interaction.
- Filter for tasks with no labels, and see selected label colors while editing a quick filter.
- Choose whether a quick filter matches subtasks. Matching subtasks retain their parent for context; context-only parents are identified separately.

## More consistent editing and navigation

- Keep the inline task composer above the phone keyboard, and retain typed text when saving fails, including after a board redraw.
- Save operations show progress and prevent editors from closing partway through a write. A failed settings save restores the previous in-memory settings.
- Keyboard focus returns to the relevant control after redraws and menu dismissal. Task action names identify the task they affect.
- Single-column boards have previous/next controls alongside swiping. Wheel and trackpad navigation have explicit paging support.
- Bulk selection includes subtasks displayed as separate cards. Due dates, priorities and moves can apply to those cards; label edits leave subtasks unchanged and report that clearly. Selection counts and messages distinguish tasks outside the current view.

## Use boards from agents and scripts

Desktop Obsidian's CLI can list boards and tasks, capture new tasks, move or edit cards, apply bulk changes and undo supported operations. Commands use the plugin's normal task-writing safeguards. See the [CLI guide](https://github.com/mason-bryant/obsidian-task-trellis/blob/0.1.17/docs/cli.md) for setup and examples. These commands require desktop Obsidian; phone capture continues to use the iOS shortcut.

## Validation and compatibility

609 application tests and 8 shortcut tests passed, along with lint, TypeScript checking, production packaging and the harness build. Browser checks covered light/dark themes, toolbar spacing and resizing across the 600px single-column breakpoint. Native macOS and iPhone checks covered settings reordering, task capture, labels, card movement and Undo, paging, scrolling and toolbar clearance. The maintainer separately confirmed software-keyboard clearance and dragging between columns on the phone. See the [pre-release report](https://github.com/mason-bryant/obsidian-task-trellis/blob/0.1.17/docs/qa/pre-release-2026-10-28.md) for evidence and remaining coverage limits.

Requires Obsidian **1.13.7 or later**. Existing boards and notes remain compatible; no manual migration is required. Android and a fresh VoiceOver pass were not tested for this release.

Future releases now require their own committed release-note document; publishing uses that document as the release description.
